# 채널 고정 공지 원문

텔레그램 채널(`@catholic_univ_notice`)에 **고정(pin)** 할 안내문. 아래 내용을 그대로 복사해 게시한다.

게시판 목록은 [cuk_bot/config.py](../cuk_bot/config.py) 의 `BOARDS` 와 일치해야 한다. **게시판을 추가·제거하면 이 공지도 함께 고친다.**

---

```
📢 가톨릭대 게시판 알리미

흩어진 공지 게시판을 모아 "기한 내에 해야 할 일"만 골라 알립니다.

■ 확인하는 게시판 (11곳)
· 본교 공지사항(전체) / 행사안내
· 기숙사 K관·A관 — 일반공지 / 입퇴사공지
· 기숙사 프란치스코관 — 일반공지 / 입퇴사공지
· 프랑스어문화학과 — 공지 / 채용정보
· 취·창업처 정보게시판
· 국제교류처 교환학생·파견
· 학부대학 알림마당

■ 확인 간격
· 24시간, 30분마다
· 매일 08:00 — 어제 공지 묶음 + 마감 임박 알림
(자동 실행 특성상 최대 30분 지연될 수 있습니다)

■ 알림 종류
🔔 신청·제출이 필요한 공지 → 발견 즉시
📰 그 외 공지 → 다음 날 08:00 한 번에
⏰ 마감 D-7 / D-3 / D-1 → 08:00 재알림
☀️ 새 공지가 없는 날에도 아침 인사를 보냅니다
   (이 메시지가 안 오는 날은 봇에 문제가 생긴 것입니다)

■ 한계 — 반드시 읽어주세요
· 학교가 공지를 이미지로 올리는 경우가 많습니다.
  마감일을 잘못 읽거나 못 읽을 수 있습니다
· 첨부파일(HWP) 내용은 읽지 않습니다
· 로그인이 필요한 게시판(트리니티·사이버캠퍼스)은 대상이 아닙니다
· ⚠️ 표시는 마감일이 불확실하다는 뜻입니다
· 🖼 표시는 본문이 이미지라 판독한 결과라는 뜻입니다

👉 최종 확인은 반드시 원문 공지로 하세요.
   이 봇은 보조 수단이지 유일한 확인 수단이 아닙니다.
```

---

## 왜 한계를 이렇게 길게 쓰는가

본문 텍스트 확보율이 **34%** 다. 기숙사 입퇴사공지는 0~25%로, 하필 이 프로젝트가 존재하는 이유인 게시판이 가장 나쁘다([M1_RESULT.md](M1_RESULT.md)). 나머지는 스크린샷을 판독해 채우지만 판독은 틀릴 수 있다.

이 봇을 유일한 확인 수단으로 믿는 순간, 놓쳤을 때의 피해가 봇이 없을 때보다 커진다 — 확인했다고 안심하기 때문이다. 그래서 한계를 눈에 띄게 적는다.
